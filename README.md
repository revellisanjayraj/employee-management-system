  # Employee Management System

  A simple and dynamic **CRUD Web Application** built using **Vue.js, Axios, and MockAPI** to manage employee records.

  ---

  ## 📌 Features

  * ➕ Add Employee
  * 📋 View Employees
  * ✏️ Update Employee
  * ❌ Delete Employee
  * 🔄 Real-time API integration using Axios
  * 🎨 Responsive UI using Bootstrap

  ---

  ## 🛠️ Technologies Used

  * Vue.js 3
  * Axios
  * Bootstrap 5
  * MockAPI

  ---

  ## 📂 Project Structure

  ```
  src/
  │
  ├── components/
  │   ├── AddEmployees.vue
  │   ├── Employees.vue
  │   └── UpdateEmployee.vue
  │
  ├── App.vue
  └── main.js
  ```

  ---

  ## 🚀 How to Run the Project

  1. Clone the repository

  ```
  git clone https://github.com/your-username/employee-management-system.git
  ```

  2. Navigate to project folder

  ```
  cd employee-management-system
  ```

  3. Install dependencies

  ```
  npm install
  ```

  4. Run the development server

  ```
  npm run dev
  ```
